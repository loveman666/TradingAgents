# 全球宏观经济与小米集团（1810.HK）交易策略报告
**日期：** 2026年05月05日

## 一、 全球宏观经济概况：通胀阴霾与能源压力
当前全球经济正处于一个复杂的“拉锯战”阶段。尽管科技板块在4月表现强劲，但宏观层面的不确定性正在上升。

1.  **通胀与美联储政策：** 通胀依然具有高度粘性。美联储在最近的会议上维持利率不变，并警告由于油价飙升，通胀压力可能持续。摩根士丹利等机构已将降息预期推迟至2027年初，这意味着“高利率更久（Higher for Longer）”的计价逻辑将继续主导市场。
2.  **能源与大宗商品：** 油价在100美元/桶附近波动，中东冲突（特别是涉及伊朗的局势）是主要推手。世界银行预计2026年能源价格可能跳升24%，大宗商品整体价格将上涨16%，这不仅直接推高生产成本，也严重抑制了消费者的自由支配开支。
3.  **消费者信心与K型复苏：** 市场呈现明显的K型背离：资产持有者（如股市投资者）受益于美股高点，但普通薪资阶层因高油价、高食品价格和高房贷利率而感到生活压力巨大，消费者信心处于历史低位。
4.  **外汇市场：** 日本央行在160日元/美元这一“防线”附近频繁干预。高盛预测日本拥有足够的储备进行更多次的干预，但这反映了美元走强对全球流动性的持续挤压。

## 二、 小米集团（1810.HK）专项分析：汽车业务成为新增长引擎
小米集团在2026年上半年的表现令人瞩目，尤其是在跨界进入电动汽车（EV）领域后，展现了极强的竞争力。

1.  **SU7 电动车爆单：** 最新数据显示，更新版小米 SU7 轿车的订单已突破 70,000 辆。作为特斯拉 Model 3 的直接竞争对手，小米在特斯拉今年不打算在中国发布 Model 3 改款的情况下，成功抢占了市场先机。
2.  **市场地位重塑：** 在中国车企整体面临补贴退坡和价格战的背景下，小米的表现优于同行（如理想、蔚来）。甚至行业领头羊比亚迪（BYD）也承认，其国内销售下滑的部分压力来自小米等新势力竞争对手的冲击。
3.  **知识产权保障：** 小米近期与 InterDigital 续签了全球专利许可协议，确保了其在智能手机和 IoT 设备领域的技术合规性，为全球化扩张铺平了法律道路。
4.  **生态链协同：** 小米“人车家全生态”战略进入收获期，智能手机业务保持稳健，同时高端化转型和汽车业务的成功正在提升品牌整体估值上限。
